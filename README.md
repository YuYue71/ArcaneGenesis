# ArcaneGenesis
### 未知異世界設定集
### 策劃細節
- 【主角身份】
   - 未知身世的少女-Luna
   
- 【世界背景】
   - 充滿魔物的黑暗森林

- 【核心冲突】
   - 找尋自己身世的秘密

- 【参考游戏的故事风格】
   - 空洞骑士：神秘、破碎的世界背景，通过环境叙事
   - 小小夢魘: 黑暗帶點恐懼感的故事背景
   - MO:Astray: 循序漸進解開謎題的敘事感
   - 泰拉瑞亚灾厄：渐进式的难度和挑战

- 【关键的5个故事节点】
   - 1.主角從森林中的一棟破舊小木屋醒來,什麼都不記得,只能一昧迷茫的前行
   - 2.觸發關鍵事件,在痛苦中陷入深度回想,慢慢想起零碎的記憶
   - 3.使用殘破的記憶碎片尋找線索,並前往各遺址
   - 4.發現自己的身份以及使命
   - 5.完成使命遭到封印，结局


### Prototype故事框架：
- 【Prototype的故事背景】
> 簡述
  - 背景："你是這個世界的守護神，在前年前遭到魔王的偷襲力量與記憶遭到封印陷入沉睡千年,醒來後意識碎片附身到了一名身處魔森林中前賢者的小木屋中遭到層層結界保護的少女身上,該少女的身世背景是在守護神隕落後百年間出現的一位挺身而出反抗魔王的少年的妹妹,少年臨終前用最後的心願像賢者定下契約使用自己的生命交易保護妹妹千年"
- prototype：
  - 一個破舊小木屋的臥室中
  - 主角從床上醒來
  - 探索周遭,發現一些道具與一本賢者的日記
  - 玩家必須離開這裡向外探索
  - 躲避魔物的同時變尋找自身身世的秘密
  - 一邊推進劇情一邊取回力量
  - 最終取回部分力量與記憶,知曉了自己的使命
  - 結局-遲來千年的救世主擊敗魔王拯救了世界,卻失去了一切
