# ArcaneGenesis
### 未知異世界設定集
### 策劃細節
- 【主角身份】
   - 未知身世的少女-Luna
   
- 【世界背景】
   - 充滿魔物的黑暗森林

- 【核心冲突】
   - 找尋自己身世的秘密

- 【参考游戏的故事风格】
   - 空洞骑士：神秘、破碎的世界背景，通过环境叙事
   - 小小夢魘: 黑暗帶點恐懼感的故事背景
   - MO:Astray: 循序漸進解開謎題的敘事感
   - 泰拉瑞亚灾厄：渐进式的难度和挑战

- 【关键的5个故事节点】
   - 1.主角從森林中的一棟破舊小木屋醒來,什麼都不記得,只能一昧迷茫的前行
   - 2.觸發關鍵事件,在痛苦中陷入深度回想,慢慢想起零碎的記憶
   - 3.使用殘破的記憶碎片尋找線索,並前往各遺址
   - 4.發現自己的身份以及使命
   - 5.完成使命遭到封印，结局


### Prototype故事框架：
- 【Prototype的故事背景】
> 簡述
  - 背景："你是這個世界的守護神，在千年前遭到魔王的偷襲力量與記憶遭到封印陷入沉睡千年,醒來後意識碎片附身到了一名身處魔森林中前賢者的小木屋中遭到層層結界保護的少女身上,該少女的身世背景是在守護神隕落後百年間出現的一位挺身而出反抗魔王的少年的妹妹,少年臨終前用最後的心願像賢者定下契約使用自己的生命交易保護妹妹千年"
- prototype：
  - 一個破舊小木屋的臥室中
  - 主角從床上醒來
  - 探索周遭,發現一些道具與一本賢者的日記
  - 玩家必須離開這裡向外探索
  - 躲避魔物的同時變尋找自身身世的秘密
  - 一邊推進劇情一邊取回力量
  - 最終取回部分力量與記憶,知曉了自己的使命
  - 結局-遲來千年的救世主擊敗魔王拯救了世界取回了部分的記憶,卻因此得知自己早已失去的一切
> 劇本關鍵 "藏刀" 要藏40米大刀,而且要藏的夠深

- 故事敘述:
  ```bash
  在一座充滿混沌與邪惡的大森林中有一棟受到強大結界所保護的破舊小木屋,
  小木屋內沉睡著一位受到封印與結界保護而稚嫩的如精靈般的少女,
  這一天,少女莫名的醒了過來,
  她環顧四周,不知為何感到一種既熟悉又陌生的感覺,
  她試圖回憶,但是卻一點也想不起來,唯獨稍微想起自己的名字 "露娜(Luna)"
  這象徵著月亮的名字,是誰為她而取,又是為什麼,她一點也想不起來,
  她嘗試從床上站起來,剛開始站立猶如長年沒使用雙腿一樣站的非常不穩而摔在了地上,
  她扶著床再次嘗試起身,這次稍微找回了站立的感覺,緩緩的顫抖著雙腿站了起來,
  她扶著牆面緩慢行走,走到了一張腐朽的木桌前,
  木桌上擺著一本日記,一張看似自己與另一位少年的合照和一束看似原本潔白的花朵("雪滴花" 這是伏筆)已枯萎發黑,唯獨最後一片花瓣仍透著慘白的微光,在黑暗的室內顯得格外孤寂
  她看著這張照片,有種說不出來的熟悉感,就像是遺失的拼圖終於歸位,卻發現邊緣早已被鮮血浸透,
  她明明不記得這名少年,眼角卻不自覺地滑下了一滴灼熱的淚,那滴淚落在發黑的雪滴花瓣上,
  [此處無靈感暫時斷更]
  ```
- 後續大致走向:
  ```bash
  Luna閱讀了日記,解開木屋的結界向外探索
  在森林中躲避或逃離魔物不斷逃跑探索
  意外進入古老的遺跡,在遺跡中躲避魔物最後取得一塊發光的碎片
  隨後一陣刺眼的白光Luna看見了些許千年前的記憶幻覺(少年獨自斬殺魔物),然後被傳送到了遺跡的出口並學會了發射白光進行攻擊
  繼續前行,途中慢慢學習使用白光攻擊並一路擊殺部分魔物
  途中有各種障礙阻擋,懸崖,毒刺藤,河流,瀑布等等阻礙,同時也學會了如何使用衝刺
  到達了第二座遺跡

  [此處還在想]

  她成功擊敗了魔王
  魔王隕落的同時Luna身體湧現白光,隨後從她身上分離出了一顆光球
  光球緩慢的飛到Luna面前並幻化成了與Luna長相一模一樣但全身純白的發光的少女
  幾秒後少女低著頭說出了"對不起",接著緩緩的抬起頭並露出一副溫柔的微笑,緊接著說"謝謝妳"
  隨後少女發出耀眼的白光消失了,少女消失後Luna突然感到一陣頭暈緩慢的閉起眼睛並伴隨著天上的流星一同墜落,墜落的同時Luna的周圍出現一層結界保護她
  玩家視角跟隨Luna朝向一開始小木屋的位置墜落
  墜落途中經過遺跡時玩家視角浮現出當時在遺跡沒能看到的幻象結局
  最後伴隨著畫面緩慢變黑墜落到小木屋前的森林中
  重新浮現畫面時此時的Luna只能左右移動
  Luna緩慢走向小木屋中
  查看木桌上的相片進入結局動畫
  
  結局動畫:
  第一人稱視角,Luna拿著相片緩慢的流下淚水並緩緩的說出"哥..哥....",落淚幾秒後世界切換到雪滴花的視角,微風吹過最後的那朵花瓣不是落到桌上,而是隨風飄向了窗外
  畫面切換到當時幫助過的倖存者,他們看見天上眾多流星劃過,唯獨一顆落在了森林中,他們進入森林查看,並找到了這間小木屋
  視角切換到掉在地上並有點碎裂的相片,此時畫面中可見相片右上角有著一隻纖細並早已沒了血色的手躺在那裡
  畫面漸暗,出現三十年後,畫面緩慢恢復,並呈現出一張繁榮的城鎮街道上赫然豎立著這對兄妹的雕像,下方刻著救世主的字樣
  畫面漸暗進入成員致謝名單END
  ```
